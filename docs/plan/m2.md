# M2 plan: security features and dashboard

Done before this plan: approvals inbox (CLI, FR-POL-3 partly), risk tiers (FR-POL-2), MCP proxy with pinning (FR-MCP-1..3), budgets and context warnings (FR-GW-4/5), memory check and llama.cpp slots (FR-GW-9/10).

Order: protections first, each with a CLI; then the dashboard on top of them; then client and agent testing.

| Task | What | Requirements |
|---|---|---|
| T2.1 | **Redaction scanner** on traffic Cairnward terminates (hosted model calls, MCP tool calls): secrets, emails, phones, ID-like numbers, custom regexes. `redaction = warn`: findings recorded and flagged; `enforce`: secrets block, personal data ask. Findings audited as kinds and counts, never the text | FR-RED-1 |
| T2.2 | **Egress report** from the audit log: per host, with connections, bytes and decisions, filtered by run, client, conversation, environment or time; text, JSON and CSV | FR-EGR-1 |
| T2.3 | **Audit anchoring**: Ed25519-signed checkpoints committed to a private git repo (deploy key), hourly in `serve` and on demand; `audit verify --anchors` | FR-AUD-4 |
| T2.4 | **Vault CLI and retention**: `cairnward vault list/show/search/delete/restore/export`, retention per environment, `vault = "digests"` storing digests only; audit log filters and export | FR-VLT-4, FR-AUD-3 (CLI) |
| T2.5 | **Locking**: passphrase lock per conversation (age scrypt wrapping of the conversation key), unlock for a session, optional recovery key; locked conversations never go to hosted backends; passphrase never logged | FR-ENC-1, FR-ENC-2 |
| T2.6 | **User-only confirmations with provenance**; approvals batching; approvals that survive client retries | FR-POL-4, FR-POL-3, FR-POL-5 |
| T2.7 | **Dashboard** (Svelte, built offline, served by the core on loopback): login link, Host/Origin/CSRF; approvals, activity, audit, egress, vault (with shortcuts), MCP servers, settings; WCAG 2.2 AA checks | FR-DASH-1..3, FR-VLT-3, FR-PRIV-4 |
| T2.8 | **Model downloads** through egress: GGUF/safetensors only, SHA-256 verified, audited | FR-SUP-2 |
| T2.9 | **Clients and agents**: Open WebUI, Jan and a third client tested; container templates on an internal-only network; agent prompt sizes recorded and flagged | FR-CLI-1/2, FR-ISO-4, FR-AGT-1 |
| T2.10 | Skills served over MCP; research tools over MCP once `lit.ask` (T1.3) exists | FR-MCP-4, FR-RES-10 |
