- **T-26:** the first streamed reply from a model not yet known to write reasoning into its answer
  still reaches the client. Non-streamed replies and later calls are clean.
- **Research library:** lockable now (T-24), but plain while unlocked, and its source PDFs aren't
  encrypted. There's no timed unlock as for conversations.
- **Restoring locked items:** the keys and the sealed library files come back in a backup, but
  only conversations are imported automatically; job, run and library files are copied by hand.
- **Locking:** run snapshots can't be locked (they're per workspace), and earlier plaintext isn't
  erased from free disk space or old backups.
- **Coverage:** `core/server.py`, which starts the sandbox, is left out of the coverage count. Only
  the isolation job runs it.
- **Unexplained:** one slow fast-model run in the first-token measurements, and q5's original
  failure in the first eval.
