# M3 plan: hardening, reuse, data safety, research connectors

Decided with the owner on 2026-11-02 (spec D65–D71). Done before this plan: M0–M2, M1 (T1.1–T1.11), PaperQA2 deep engine in jobs, reviews that pick their papers at start (`--files`).

While the owner can't run real-model checks, work goes on in parallel; the evals and the client checklist run as soon as the reference machine is available (T3.1 makes that one command).

| Task | What | Requirements |
|---|---|---|
| T3.1 | ✅ **Hardening:** every end-to-end flow in both server modes (isolated, single process); fuzzing of egress request parsing, MCP messages and PDF input; `cairnward check` runs `evals/pdf_qa --compare` and the client checks and writes one readable report; review of NVIDIA OpenShell (Apache-2.0, alpha): what to borrow, e.g. network rules tied to the program that opened the connection | NFR testing, FR-ISO-5 |
| T3.2 | ✅ **Reuse swaps:** MCP proxy plumbing on the official MCP Python SDK (ADR-0015 amendment; canonical-JSON pin hashes, pins migrated); reference formatting with a selectable CSL engine (citeproc-js, pandoc, built-in fallback; D67 revised) and the official CSL styles (APA 7, IEEE; vendored, hash-pinned) | FR-MCP-1..3, FR-RES-6 |
| T3.3 | ✅ **Backups:** restic (always encrypted) of vault, library and artifacts; retention; restore to a date; purge rewrites snapshots and prunes, with a pending state and retries; modes none / on_demand / auto | FR-SYNC-1, -3, -6, -8 |
| T3.4 | ✅ **Zotero** (local API, read-only) as a library source; **academic APIs** (OpenAlex, Semantic Scholar, arXiv, Crossref, PubMed) through egress, opt-in, cached, audited; open-access PDFs into a library | FR-RES-7, -8, -9 |
| T3.5 | **Full review pipeline:** screening on titles/abstracts with the fast model (D63), extraction from included papers, a synthesis section, comparison table, `.bib` export | FR-RES-4 |
| T3.6 | **Richer PDF parsing**, optional sandboxed workers with split roles: Docling (body text, tables, OCR), GROBID (metadata, reference list); per library; pypdfium2 stays the default and fallback | D68 |
| T3.7 | **Hosted providers:** OpenRouter, DeepSeek API, Alibaba Model Studio, Groq, Cerebras, Gemini; denied by default, never for locked conversations, ☁ marking; backends that may train on prompts marked so and allowed only in scratch environments unless that restriction is switched off (audited) | FR-BACK-4, -5, D70 |
| T3.8 | **Drive mirror** (read-only, rclone) into a library, with preview | FR-SYNC-2 |
| T3.9 | **Also included:** Presidio as an optional redaction worker; OpenTelemetry GenAI export (local, off by default); RFC 3161 timestamps for audit checkpoints (opt-in) | FR-RED-2, FR-AUD-5, D69 |

**Follow-ups from the OpenShell review** ([reviews/openshell-2026-11.md](../reviews/openshell-2026-11.md)), small, done alongside M3: pin the executable `cairnward run` starts; risk checks on settings changes (metadata addresses, wildcard or private allow-list entries, hosted backends for locked environments); stop runs when their egress process goes away. Not scheduled: OpenShell as an optional second sandbox backend.

**Deferred (D71):** multi-device replication (FR-SYNC-4); multi-agent YAML workflows (FR-RES-11).

**Owner-side, when the reference machine is available:** `cairnward check` (T3.1) with the real models; results recorded in `docs/bench/`. Findings there take priority over the remaining M3 tasks.
