## Environment notes for cloud sessions
A fresh container lacks these tools, and with them missing many tests skip quietly. This session
installed them, and they're worth installing again before testing:
- **System packages:** `apt-get install restic openssh-client bubblewrap socat ripgrep`.
- **The sandbox:** `npm ci` in `spikes/t06-sandbox`, then
  `CAIRNWARD_SRT="node $PWD/spikes/t06-sandbox/node_modules/@anthropic-ai/sandbox-runtime/dist/cli.js"`.
- **The Rust binaries:** `cargo build --manifest-path rust/Cargo.toml`. The Rust differential
  tests and the Rust half of the egress tests skip without them.
- **SQLCipher:** comes with `uv sync` on Linux x86-64 (dev group).

With all of these, the last local run was 812 passed, 39 skipped, plus the isolation suite at
37 passed, 2 skipped.
