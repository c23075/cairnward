# Security

## Reporting a problem
Open a private advisory on this repository (Security → Report a vulnerability). Please don't open a
public issue. This is a one-person project, so there's no response time promise.

## What's been reviewed
Only the assistant that wrote the code has reviewed its security. There's been no outside review or
penetration test. The threat model is in [docs/threat-model.md](docs/threat-model.md), with reviews
in [docs/reviews/](docs/reviews/).

## Versions
Only the latest release gets fixes.
